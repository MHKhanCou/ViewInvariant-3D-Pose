A Lightweight, Training-Free, Reliability-Aware Geometric Canonicalization Framework for Cross-View Comparability of Frozen Monocular 3D Pose Predictions

Undergraduate Thesis Defense · August 2026

Frozen model: MotionAGFormer-XS · Dataset: MPI-INF-3DHP (local S1, S2)

Problem

  • Monocular 3D pose predictions live in camera-relative coordinates — the same motion seen by two cameras produces two different 3D poses.
  • Comparing predictions across views (gait analysis, sports, multi-device capture) requires a shared frame — normally obtained by retraining or camera calibration.
  • Goal: cross-view comparability for a frozen model, no training, no extrinsics — plus a signal for when not to trust the output.

Claim discipline: the contribution is comparability, never accuracy improvement. Prediction-vs-prediction distance is cross-view joint distance, never MPJPE.

Method — deterministic body-frame construction

  • Gram-Schmidt body frame: y = torso vertical, x = hip line, z = x×y. Re-express joints in this frame. O(17) per frame, zero parameters.
  • Reliability score: geometric mean of 6 training-free components (axis conditioning, torso-hip angle, bilateral symmetry, bone ratios, detector confidence, temporal stability).
  • Hard gates: degenerate geometry → abstain loudly, never silently.
  • Multi-scale extension: per-limb frames (torso, 2 arms, 2 legs) built by the same construction.

Protocol — corrected, auditable

  • We found and fixed our own protocol flaw: earlier numbers lifted a single frame repeated 27×. The corrected protocol uses true 27-frame detection windows; only fully-windowed frames are reported.
  • 8 synchronized cameras (S1/Seq1) → 28 pairs + held-out subject S2 → 29 pairs × 54 frames, from already-local AVIs. Frame↔annotation sync verified by GT overlay.
  • Development pair labeled: all tuning happened on S1 cam0-1. The other 27 pairs + S2 are held out.
  • Raw root-relative outputs only — no display transforms in any quantitative path.

Invalidated history, owned up front: 67% and 40% used display post-processing and repeated frames — invalid. Legacy 28.4% is valid but superseded by the corrected protocol.

Result 2 — how close to the best possible rigid alignment?

Per-frame Procrustes oracle: the optimal rotation, computable only with both poses jointly — a lower bound no rotation method can beat.

The training-free frame approaches the oracle on many pairs (cam5-cam8: 0.0457 vs 0.0418).

The oracle needs both views simultaneously; our method canonicalizes each view independently — deployable where the oracle is not.

Result 3 — anchored against ground truth

  • GT bridge validated: world-transformed GT across cameras agrees to 0.0 mm.
  • Per-frame GT error = similarity-aligned (Umeyama) joint distance — not MPJPE.
ρ(canonical cross-view distance, GT error) = +0.601

vs +0.188 for raw distance (p ≈ 10⁻¹⁵⁴, n = 1566).

Canonicalization makes cross-view consistency a 3× stronger training-free proxy for actual prediction error — consistency is necessary-not-sufficient, and we say so, but it demonstrably carries error information.

  • 2240 corrupted lifts, 5 physically-motivated operators, seeded, identity controls exact.

Negative result — retrieval

  • Cross-view retrieval got worse under canonicalization (R@1 0.02 → 0.00, MRR −6.9%).
  • Expected in hindsight: retrieval across similar standing poses partly relies on view information — which canonicalization removes by construction.
  • This delimits scope: the framework is for cross-view comparison, not general-purpose representation.

A method that helped every task would be suspicious. This result is evidence the method does exactly what it claims — removes view information.

Limitations — stated, not hidden

  • One dataset, two subjects, one model. Model-independent by construction (consumes any 17×3 pose); model-agnostic is untested and not claimed.
  • Reliability on clean data correlates with error only moderately (ρ −0.24; per-camera −0.75…+0.71) — clean studio error variance is small (restriction of range). Strong under degradation (−0.813).
  • Near-aligned camera pairs gain little and can regress slightly (−6.1% worst).
  • Abstention threshold 0.5 frozen at implementation time — deliberately not calibrated on reporting pairs.

Contributions

  • 1 · Training-free geometric canonicalization — +32.4% mean cross-view improvement on 27 held-out pairs; approaches the per-pair Procrustes oracle.
  • 2 · Training-free reliability estimation — tracks induced error at ρ −0.813; 100% abstention on joint dropout; 0% false abstention on clean data.
  • 3 · Analytical consistency metrics — canonical cross-view distance is a 3× stronger GT-error proxy than raw (ρ +0.601 vs +0.188).
  • 4 · Integrated framework — plus a multi-scale extension improving every pair while preserving error information.
  • 5 · Training-free multi-view selection & fusion — a shared body frame turns N uncalibrated views into a selectable, fusable set: +33.8% over an arbitrary view, within 12% of a GT-requiring oracle.
