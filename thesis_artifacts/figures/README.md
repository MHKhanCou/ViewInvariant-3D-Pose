# Qualitative Visualization Figures

These figures are generated from the MotionAGFormer-XS demo pipeline using YOLOv8-pose on sample frames from the `person.mp4` video.

## Important Disclaimer

**These are qualitative visualizations only.** They demonstrate the pipeline works on in-the-wild images. They do not represent:
- Metric 3D reconstruction accuracy
- Cross-view consistency
- Benchmark performance

The 3D poses are produced by a 2D-to-3D lifting model trained on Human3.6M lab data. Performance on in-the-wild images is affected by domain shift between YOLOv8-pose detections and the Stacked-Hourglass detections used during training.

## What These Figures Show

- **Left panel**: Original RGB image with YOLOv8-pose 2D skeleton overlay (COCO-17 format)
- **Right panel**: 3D pose reconstruction via MotionAGFormer-XS

### Camera-relative mode
- Root joint zeroed, non-root joints retain absolute positions
- Rendered with fixed viewing angle (elev=15, azim=70)
- Matches official MotionAGFormer demo style

### Canonical mode
- Body-fixed coordinate system (vertical + hip axes)
- Equal axis scaling, auto-fit bounds
- Joint markers and thicker bone lines
